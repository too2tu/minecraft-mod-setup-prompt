What this does: Paste everything below the line into Claude Code on your Mac or Windows PC. Claude sets up a complete Minecraft Java Edition mod development environment: it installs the right Java and IntelliJ IDEA, downloads the official NeoForge mod template, builds a small "hello world" mod, and checks that Minecraft starts with your mod loaded. Then it opens the project in IntelliJ, shows you how to run it from there, and asks what mod you want to make. 

You don't need to sign in to Minecraft for the test game. To play your finished mod in the normal game, you'll need your own Minecraft Java Edition account.

**Optional:** on the "Minecraft version" line below, pick a version. Leave it blank and Claude uses the newest version NeoForge has a template for.
